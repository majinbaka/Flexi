# Documentation

Current Flexi documentation. Release and implementation status is maintained
in Storybook's `Current Product State` page; the active backlog is maintained
in `process/deferred-work.md`.

## Layout

- [`process/`](./process) -- living process documentation, including
  `deferred-work.md`, the current verified backlog.

Historical plans, specifications, research digests and audit snapshots are not
retained. Refer to code, tests and **Docs → Current Product State** for
current behavior.
