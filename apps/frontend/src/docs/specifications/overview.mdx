# Specifications

Các trang này là đặc tả sống được đối chiếu với code hiện tại. Chúng mô tả
hành vi đã có, không phải backlog hay cam kết sản phẩm. API backend có tiền tố
`/api` và tất cả phản hồi dùng envelope `{ success, data, error }`.

## Phạm vi chưa đặc tả như một chức năng hoàn chỉnh

`workflows`, `pages`, `cron-jobs`, `mail-templates`, `wiki`, `i18n`,
`settings` và `logs` hiện có route nhận diện module nhưng backend trả
`{ status: 'not-implemented' }` và frontend hiển thị `PlaceholderPage`.
Không có flow nghiệp vụ hoàn chỉnh để đặc tả từ code hiện tại.

Riêng `settings`, trang **Core System Configuration** lưu contract mục tiêu và
đối chiếu với phần bootstrap đã có; nó không tuyên bố module đã khả dụng.

## Cách kiểm tra

- Xem story cạnh trang UI để kiểm tra loading, lỗi, empty và permission UI.
- Đối chiếu endpoint với controller/service được ghi trong mỗi trang.
- Storybook dùng mock có chủ đích; kết quả story không thay thế kiểm thử tích
  hợp với backend/database/queue.
