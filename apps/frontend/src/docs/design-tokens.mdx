# Design Tokens

Every design value in this app comes from the Stitch "Flexi Low-code Design
System" project, projected into two files that must stay in step:

- [`tailwind.config.js`](../../tailwind.config.js) -- the utilities used in
  component classes (`bg-surface`, `text-body-sm`, `p-md`, ...).
- [`src/styles/tokens.css`](../styles/tokens.css) -- the same values as CSS
  custom properties (`--color-surface`, `--space-md`, ...), for the cases
  Tailwind cannot reach: raw CSS, injected markup, and user-authored
  low-code content styled at runtime.

Regenerate both from the Stitch DESIGN.md rather than hand-editing either
one, and never hardcode a color or size in a component.

## Color

Colors follow the Material 3 role naming: a role and its `on-` pair are
guaranteed to be legible together, so use them as pairs
(`bg-primary text-on-primary`) instead of mixing roles by eye.
