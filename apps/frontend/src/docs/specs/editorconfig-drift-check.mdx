# Add editorconfig compliance check for CI

## Intent

**Problem:** The repo's root `.editorconfig` was added with no enforcement mechanism — new commits could silently violate its indentation/EOL/charset/final-newline rules with no CI signal, and pre-existing drift in already-committed files was never checked.

**Approach:** Add `editorconfig-checker` as a devDependency, a `pnpm editorconfig:check` script mirroring `format:check`'s pattern, and a CI step gating on it. Exclude vendored BMad/Claude tooling and Prisma-generated files the same way `.prettierignore`/ESLint already do. Fix the one real gap the check surfaced: `.editorconfig`'s `indent_size = 2` doesn't account for legitimate 3-space markdown numbered-list continuation, so `.md`/`.mdx` now `unset` that rule.
